# Architecture Description

Amazon EC2 instances continuously send performance metrics to Amazon CloudWatch.

CloudWatch monitors metrics such as CPU Utilization against user-defined threshold values.

When a configured threshold is exceeded, CloudWatch changes the alarm state and performs the configured alarm actions.

Amazon Simple Notification Service (SNS) sends real-time email notifications to subscribed users whenever an alarm is triggered.

CloudWatch can also automatically stop, reboot, terminate, or recover Amazon EC2 instances based on the configured alarm action.

Windows EC2 instances were accessed using Remote Desktop Protocol (RDP), while Linux EC2 instances were remotely administered through Secure Shell (SSH) using MobaXterm and a PEM private key.

# Project Overview

This project demonstrates the implementation of an automated monitoring and alerting solution using Amazon CloudWatch and Amazon Simple Notification Service (SNS). CloudWatch alarms were configured to monitor CPU Utilization for both Windows and Linux Amazon EC2 instances. Whenever the configured threshold was exceeded, CloudWatch generated alarms, executed automated EC2 actions when configured, and sent real-time notifications through SNS. The project provided practical experience in cloud monitoring, infrastructure management, and automated incident response.

# Implementation

## 1. Amazon SNS Configuration

Amazon SNS was configured to deliver CloudWatch alarm notifications.

### Activities Performed

- Created an Amazon SNS Topic.
- Created an Email Subscription.
- Confirmed the subscription through the verification email.
- Verified successful notification delivery.

### Outcome

Successfully configured Amazon SNS for CloudWatch alarm notifications.

---

## 2. Windows EC2 Monitoring

CloudWatch alarms were created directly from the Windows Amazon EC2 instance.

### Activities Performed

- Selected the Windows EC2 instance.
- Verified Remote Desktop security group configuration.
- Created a Status Check Alarm.
- Selected the CPU Utilization metric.
- Configured threshold values.
- Selected alarm conditions.
- Enabled alarm actions.
- Configured SNS notifications.

### Outcome

Successfully monitored the Windows Amazon EC2 instance using Amazon CloudWatch.

---

## 3. CloudWatch Alarm Creation

CloudWatch alarms were created manually from the Amazon CloudWatch Console.

### Activities Performed

- Opened the Amazon CloudWatch Console.
- Selected EC2 Per-Instance Metrics.
- Chose the CPU Utilization metric.
- Configured threshold values.
- Configured evaluation periods.
- Selected EC2 automated actions.
- Enabled SNS notifications.
- Assigned an alarm name.
- Created the CloudWatch alarm.

### Outcome

Successfully created CloudWatch alarms to monitor Amazon EC2 performance metrics.

---

## 4. Linux EC2 Monitoring

CloudWatch monitoring was configured for a Linux Amazon EC2 instance.

### Activities Performed

- Created a Linux EC2 instance.
- Verified Secure Shell (SSH) security group configuration.
- Configured CloudWatch alarms.
- Selected the CPU Utilization metric.
- Configured alarm thresholds.
- Enabled SNS notifications.

### Outcome

Successfully monitored Linux Amazon EC2 instance performance using Amazon CloudWatch.

---

## 5. Linux Remote Administration

The Linux Amazon EC2 instance was accessed securely using SSH.

### Activities Performed

- Opened MobaXterm.
- Created an SSH session.
- Entered the EC2 Public IPv4 address.
- Specified the username as **ec2-user**.
- Configured PEM private key authentication.
- Established the SSH connection.

### Outcome

Successfully connected to and remotely managed the Linux Amazon EC2 instance.

---

## 6. CloudWatch Alarm Management

Existing CloudWatch alarms were managed through the Amazon CloudWatch Console.

### Activities Performed

- Viewed all existing CloudWatch alarms.
- Edited alarm threshold values.
- Modified alarm actions.
- Updated SNS notification settings.
- Saved the updated alarm configuration.

### Outcome

Successfully managed and modified CloudWatch alarm configurations as required.
